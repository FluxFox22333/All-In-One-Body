# Fivefold · 五人一体 0.1.0-alpha

目标：Minecraft Java 26.3，NeoForge 26.3.0.39-beta，Java 25。
这是独立模组，不依赖 Dual Drive，也不是其修改版。请勿同时启用两个共控模组。

## 当前交付状态

首个可编译测试版。已按指定版本开发包编译，并完成六项权限逻辑自动化测试。开发专用服务器已成功加载并进入世界；开发客户端已完成模组与资源初始化。具体记录见 `VERIFICATION.md`。
尚未完成五台客户端的真实联机验收；不能据此视为已经验证可正常游玩的正式版本。

## 安装与开始

1. 五位玩家和专用服务器均安装上述同一版本 NeoForge。
2. 将 `fivefold-0.1.0-alpha.jar` 放入每个客户端以及专用服务器的 `mods` 文件夹。
   局域网开放世界时，房主客户端兼任服务器；其他四人也必须安装模组。
3. 五个人进入同一世界。进入“选项 → 五人一体”，或在游戏中按 F8。
   也可从 NeoForge 模组列表的 Fivefold 配置入口打开设置。
4. 准备作为真实身体的人点击“创建房间”。另外四人填写显示的六位房间号，点击“加入房间”。
5. 每人选择一项移动、一项鼠标、一项其他操作。同项权限不能重复归属。
6. 五人到齐且十五项权限全部分配后，房主点击“启动五人共控”，所有人返回游戏。
7. 使用 F8 随时修改分工；F10 打开自己的本地菜单。任何成员“退出并解散”都会结束整个会话。

服务器重启后需要重新组队。普通按键的物理键位沿用原版按键设置；鼠标左右键、滚轮方向、Esc、F8、F10为本测试版的固定输入。

## 默认分工（按加入顺序）

| 玩家 | 移动 | 鼠标 | 其他 |
|---|---|---|---|
| A | W 前进 | 左键 | Q 丢弃 |
| B | S 后退 | 右键 | E 打开背包 |
| C | A 左移 | 鼠标滑动 | Ctrl 疾跑 |
| D | D 右移 | 滚轮上滚 | Shift 潜行 |
| E | 空格 跳跃 | 滚轮下滚 | Esc 关闭共享界面 |

最新指定的 C/E 交换已生效。自定义分工要求每类一项，并保留原始限制：视角只能配左移或右移；Shift潜行不能配前进、后退或视角；Ctrl疾跑不能配前进或后退。按你后来的交换要求，视角与Ctrl疾跑可以配在一起。
分配操作权限不会让其他人通过改键获得该权限。

## 修改分工

带勾选标记的项目是自己当前的权限。悬停显示权限归属；队友占用的选项不可领取。
先取消自己该类别的旧选项，再领取空闲选项。两人交换时，双方先取消旧选项，再分别领取。
缺项期间停止主动身体操作；重力、世界时间和伤害继续。房主可以一键恢复全队默认分配。
每次修改携带服务器版本号，过期请求会被拒绝，避免并发覆盖。

本版本是“拆分按键”玩法：每个人仍可单独执行归属于自己的动作。
没有添加五人同时按住协作键的额外要求，也不保证每个动作都需要五人同时按键。

## 共享身体与状态

房主是唯一真实参与生存的角色。实际物品、健康、饥饿、经验、效果和属性由这个角色持有与结算。
另外四人进入旁观模式，摄像机跟随真实身体；界面显示身体的快捷栏、生命、饥饿、经验等级和效果名称。
其余四人的个人背包不会合并、复制到身体，也不会变成新的物品来源；共控结束后仍保留各自物品。
掉落和死亡只由真实身体发生一次。测试版在真实身体死亡约三秒后请求自动复活；硬核模式不支持这一流程。

正常退出或任何成员掉线会解散房间，并恢复跟随玩家之前的游戏模式。解散时留在身体附近，不回到组队前位置。
切换旁观模式前会在世界目录写入 `fivefold-recovery.json`。异常终止后再次登录时，尝试恢复记录的原游戏模式。

## 鼠标、背包与组合键

- 鼠标滑动负责人控制共享视角，以及容器界面中的绿色十字指针。
- 左右键负责人分别控制挖掘／攻击和使用／放置。左右键在容器中根据共享指针执行点击。
- Shift负责人按住Shift时，其他人的容器点击形成快捷移动。
- Q负责人对共享指针指向的槽位丢弃一个物品；Ctrl负责人同时按住Ctrl时丢弃整组。
  光标拿着物品时，Q丢弃拿着的物品。关闭容器权限归Esc负责人；E只打开背包。
- 上滚和下滚独立授权。数字键选快捷栏、中键选物品、副手交换、双击W疾跑、自动跳跃在共控游戏输入中被屏蔽。
- F8/F10始终是个人菜单入口，不属于共享Esc权限。
- 成员输入约20次/秒续期；服务器约半秒未收到输入会释放该成员的持续操作。
- 身体客户端打开本地设置／菜单时暂停执行身体的合并输入；其他人的输入不会直接驱动后台菜单。

## 首版功能范围和待联机验收项

实现了五人房间、设置界面、权限互斥、按键与视角输入合并、快捷栏方向权限、基础共享槽位容器和跟随视角。

共享容器采用统一槽位界面，不是原版完整界面的远程镜像：
- 基础物品取放、左右键分堆、Shift快捷移动和基本合成槽位已实现。
- 拖拽分配、双击收集、配方书、附魔选项、铁砧改名、交易切换、书本与告示牌编辑，以及其他模组的特殊按钮尚未实现。
- 炉子等容器显示槽位，不显示进度条、燃料条或专属装饰。
- 自定义槽位坐标超出普通容器范围的第三方容器尚未适配。
- 跟随者显示共享状态摘要，没有完整复制身体的第一人称手部动画和所有屏幕视觉效果。
- 真实五人联机、跨维度、死亡复活、骑乘、不同GUI缩放和第三方模组兼容性仍需实机验收。
- 权限校验针对本模组发出的合作输入，不应将本模组当作对抗恶意修改客户端的反作弊插件。

以上是明确的首版边界，不代表这些特殊界面已经完成。

## 建议首次验收顺序

1. 在新建测试世界五人组队，确认只有一个可碰撞、可战斗的身体。
2. 分别测试W/S/A/D/空格，并验证其余四人同按键无效。
3. C转头，A挖掘，B放置；D上滚、E下滚；尝试其他人滚动无效。
4. A按W、C按Ctrl验证疾跑；D按Shift验证潜行；A独自双击W不得疾跑。
5. B按E打开容器，C指向物品，A左键、B右键、D协助Shift，E关闭。
6. 两人互换权限，验证旧权限失效；缺项时身体停止主动输入。
7. 某人切出窗口、掉线，观察是否停止持续动作并恢复跟随玩家原模式。
8. 之后再验收受伤、死亡复活、跨维度和骑乘。

## 从源码构建

安装 JDK 25，然后运行：

- Windows：`gradlew.bat clean build`
- macOS / Linux：`./gradlew clean build`

输出：`build/libs/fivefold-0.1.0-alpha.jar`。
依赖锁定 NeoForge 26.3.0.39-beta；Minecraft 26.3 与较旧1.21系列接口不同，不能直接换版本安装。

工程包含 Gradle Wrapper、Java 源码、资源配置与权限测试。构建机器第一次运行需要从官方仓库下载依赖。
