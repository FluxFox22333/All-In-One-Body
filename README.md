# All-In-One-Body · Fivefold 多人一体

一个 Minecraft Java 多人协作模组：**2–32 名玩家共同控制一个身体**，将移动、鼠标和辅助操作分配给不同成员，一起完成生存与协作挑战。

当前源码版本为 **0.5.1-alpha**，模组 ID 为 `fivefold`。本项目采用 [MIT 许可证](LICENSE)。

## 版本要求

| 组件 | 版本 |
| --- | --- |
| Minecraft Java | 26.3 |
| NeoForge | 26.3.0.39-beta |
| Java / JDK | 25 |
| 模组 | 0.5.1-alpha |
| 网络协议 | 10 |

以上版本来自项目构建配置。所有客户端和服务器必须使用相同版本；不支持与旧版模组混用。

## 主要功能

- 2–32 人房间、服务器校验的操作权限分配，以及共享移动和视角输入。
- 房主作为实际身体，其他成员以旁观跟随方式参与共控。
- 共享背包、容器操作、原版村民交易及进度同步。
- 共享快捷栏、生命、护甲、饥饿、经验、呼吸条和主副手状态。
- 实时队友按键显示，以及带公共奖励和个人惩罚积分的协作任务。
- 成员断线时解散房间，并尝试恢复跟随成员原有游戏模式。

## 构建

安装 JDK 25，在项目根目录运行：

```sh
# macOS / Linux
./gradlew clean build
```

```bat
:: Windows
gradlew.bat clean build
```

首次构建需要联网下载 Gradle 和模组开发依赖。构建产物位于 `build/libs/fivefold-0.5.1-alpha.jar`。
单独运行逻辑测试可使用 `./gradlew test`。

`tools/build_cached.py` 支持使用已有的精确目标 API 与依赖缓存构建，
`tools/check_mixin_targets.py` 用于静态核对目标字节码；使用参数见脚本帮助。

## 安装与开始

1. 每个客户端及服务器安装表格中指定的 NeoForge 版本。
2. 将构建生成的模组 JAR 放入各自的 `mods` 文件夹，移除旧版 Fivefold。
3. 玩家进入同一世界，按 **F8** 打开多人一体设置。
4. 准备作为共享身体的玩家创建房间，其他成员通过房间号加入。
5. 分配操作权限；至少两人、所有操作被覆盖、每人同时具有鼠标和键盘操作权限，且无人拥有全部操作时，房主启动共控。
6. **F8** 查看或调整分工，**F7** 切换精简／详细／隐藏悬浮窗，**F9** 展开或翻页查看全队实时按键，**F10** 打开个人菜单；默认 **L** 查看进度。

权限可共享，单个成员可持有多个操作。三人及以上时，视角不能与前进、后退或跳跃配对；潜行不能与前进、后退或视角配对；疾跑不能与前进或后退配对。

共享身体持有实际物品与生存状态，其他成员的个人背包不会合并到身体。
服务器重启后需要重新组队；异常恢复数据写入世界目录中的 `fivefold-recovery.json`。

## 协作任务

正常 20 TPS 下每轮任务为 15 秒；全员提前完成时立即结算并发布下一项任务，下一轮重新计时 15 秒。成员轻按对应操作键，服务器检查最近 3 秒内的不同响应成员；被选中者必须参与。任务响应不会让成员获得其未分配的身体操作权限。

部分成功可积累公共奖励积分，全员成功获得更多积分并降低被选中者的惩罚积分。积分达到门槛后，给共享身体施加随机正面或负面效果。打开共享容器、身体死亡或分工不完整时暂停任务。

完整规则、变更与复测步骤见 [0.5.1 版本说明](docs/versions/Fivefold-0.5.1-说明.md)（任务完整规则见 [0.5.0](docs/versions/Fivefold-0.5.0-说明.md)）。

## 测试状态与已知限制

0.5.1 使用精确目标 API 缓存完成全部生产源码编译，103 项 JUnit 测试和 19 项静态字节码目标检查通过。
这些检查不包含实际游戏画面或多人联机验收。

**当前为 alpha 版本，尚未完成 0.5.1 的实际游戏启动、运行时 Mixin、多人联机和画面验收。**
第三方特殊容器、地图显示和手部切换动画仍可能存在差异；硬核模式不支持自动复活流程。
本模组的权限校验不应被视为对抗恶意客户端的反作弊机制。

更多技术记录见 [VERIFICATION.md](VERIFICATION.md)。请先在测试世界验证，反馈问题时附上版本、复现步骤及已脱敏日志。

## 项目结构

```text
src/main/java/        模组实现：客户端、服务器、核心逻辑、网络与 Mixin
src/main/resources/   模组元数据与 Mixin 配置
src/test/java/        核心逻辑、并发与布局测试
gradle/               Gradle Wrapper
tools/                缓存构建与字节码检查工具
docs/versions/        各版本说明与源码补丁
```

`docs/getting-started-0.1.0.md` 为历史文档，其人数、权限和功能描述不适用于当前全部功能。
本地保存的旧源码压缩包、JAR、原始环境测试报告、构建输出和运行数据由 `.gitignore` 排除，不随仓库上传。
